# Long Enchants

Fabric mod for Minecraft 1.21.11, Fabric Loader 0.18.5, and Java 21.

The `/longenchant` command supports level values up to `Long.MAX_VALUE` and numeric tooltip formatting after level 10. Levels above `Integer.MAX_VALUE` are stored exactly but mirrored to vanilla at that integer limit.

The code is experimental until compiled and tested in Minecraft.
